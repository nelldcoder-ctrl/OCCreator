                FABLE STUDIO GUIDE

                A QUICK TOUR

                A home for your stories.

                Fable helps you shape original characters, see their profile take form, and keep your cast together in one private place.

                IN THIS GUIDE

                01 Create a character 02 Character Cards 03 Lore & Story 04 Save as PDF 05 Export your work 06 Import a backup
                01

                Create a character

                Choose New character and add a name. Fill in any other details you like—your preview updates as you type. Choose Save character when you’re ready. You can return and edit it later.

                02

                Find and open Character Cards

                Scroll to Character Cards or use the side menu. Select a card to open the full profile. Use search to find a character; choose Edit in the profile to make changes. Your characters are saved in this browser.

                03

                Write and open Lore & Story

                Choose New story, then write a title and any text you want. Your draft autosaves as you work; choose Save story to add it to your story list. Select a story card to edit it. Use the preview below the list, then choose Open full preview to read it in a floating window.

                04

                Save a character or story as PDF

                Open a character profile or a story’s full preview, then choose Print / Save PDF. In the print window, select Save as PDF as the printer and save the file. The PDF is a readable copy; it does not replace your saved work.

                05

                Export a backup

                In Character Cards, choose a format and select Export all. JSON and YAML keep the character details; CSV and Text are handy for lists or reading. In Lore & Story, choose JSON or YAML, then select Export stories & drafts. This backup includes saved stories and unfinished drafts.

                06

                Import a backup

                Choose Import file in Character Cards or Lore & Story, then select a JSON or YAML backup (Character Cards also accepts CSV). New items are added; an item already in your library is updated. Keep your backup file somewhere safe.
